# Message Bomber

A desktop GUI auto-typer utility built in Python with PyQt5 and Tkinter.

## Features

- **Automated Typing:** Sends text at configurable intervals using PyAutoGUI.
- **Fail-safe:** PyAutoGUI fail-safe enabled (slam mouse to screen corner to abort).
- **Dual Interfaces:** Implementations available for both PyQt5 and Tkinter.

## Requirements

- Python 3.x
- PyQt5
- PyAutoGUI
